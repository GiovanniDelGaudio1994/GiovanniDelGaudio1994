# Risorse grafiche — RememberMe (iRem)

Questa cartella pubblica è dedicata agli asset del **prototipo universitario di Interazione Uomo–Macchina**, non al codice Android.

## Demo animata
File previsto: `rememberme-demo.gif`.

La GIF è una **ricostruzione visiva animata** basata sulle schermate del prototipo PowerPoint originale `Prototipo (2).pptx`; non è una registrazione di un'app Android in esecuzione.

Il prototipo illustrava:
1. Schermata di avvio iRem.
2. Scelta tra **Eventi** e **Ricordi**.
3. Inserimento di un evento e selezione della data.
4. Consultazione e rimozione degli eventi.
5. Galleria dei ricordi.
6. Visualizzazione di una foto-ricordo.
