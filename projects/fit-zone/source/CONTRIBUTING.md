# Contributing

For changes to this educational project:
1. Create an issue describing the change.
2. Branch from `main`, e.g. `feature/security-hardening`, `fix/booking-race`, `docs/screenshots`.
3. Keep secrets, user data and uploaded files out of commits.
4. Run `php -l` on all PHP files; add tests where feasible.
5. Open a pull request into `main`; no direct production deployment.

Copyright remains with the rightful authors. The public repository is not automatically under an open-source license.
