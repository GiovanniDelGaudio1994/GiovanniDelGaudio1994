# e-Wine — E-commerce universitario

**Progetto universitario completo · Codice applicativo riservato**

Web application sviluppata per l'insegnamento **Tecnologie per il Software Web** presso l'Università degli Studi di Salerno (A.A. 2020–2021), presentata da Giovanni Del Gaudio. Il progetto è collegato anche al percorso di Ingegneria del Software.

## Cosa realizza

Un negozio online di vini con quattro ruoli previsti dall'applicazione:

| Ruolo | Funzionalità presentate |
|---|---|
| Visitatore | Naviga catalogo e prodotti, consulta le informazioni |
| Utente registrato | Accesso, carrello, acquisti, ordini e area profilo |
| Amministratore | Gestione prodotti e utenti |
| Responsabile | Gestione degli ordini e tracciamento spedizioni |

La presentazione originale descrive inoltre la progettazione dei percorsi di navigazione e lo **schema Entity–Relationship**.

## Tecnologie

Java · JSP · Servlet · Bootstrap 4 · HTML/CSS · JavaScript · MySQL · Apache Tomcat

## Stato e riservatezza

L'autore dichiara che l'applicazione originale è funzionante. **Non è qui disponibile una demo server attiva**, e non vengono distribuiti codice sorgente completo, database, credenziali o configurazioni. La scheda e la copertina servono esclusivamente come documentazione pubblica del progetto.
